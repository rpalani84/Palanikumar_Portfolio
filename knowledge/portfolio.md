## Featured projects

### 1. AI Helpdesk Ticket Router
**Status:** Development and validation

**Problem:** Helpdesk teams need a structured way to classify incoming support tickets, identify priority, and route requests to the appropriate team.

**Approach:** Developing a Python and Streamlit application using locally hosted Ollama models. The application is designed to support ticket classification, priority detection, department routing, knowledge-base resolution suggestions, and ticket-history tracking.

**Tools:** Python, Streamlit, Ollama, local language models, and CSV-based storage.

**Outcome:** The application is undergoing validation. Production deployment and measurable business outcomes have not yet been established.

### 2. AI Knowledge Assistant
**Status:** Development experiment

**Problem:** Users need a convenient way to ask questions about information contained in reference documents.

**Approach:** Developed an experiment with document ingestion, text chunking, embeddings, local language models, and retrieval-based question answering.

**Tools:** Python, Streamlit, Ollama, Qwen2.5, nomic-embed-text, and document-processing libraries.

**Outcome:** The experiment has been used to test document indexing and knowledge retrieval. Formal performance benchmarks have not been established.

### 3. Portfolio Chat Assistant
**Status:** Development and testing

**Problem:** Portfolio visitors need an easy way to ask questions about a professional's experience, skills, and projects.

**Approach:** Building a portfolio website with a local AI assistant that uses owner-approved Markdown content as its knowledge source. The design emphasizes grounded answers and avoiding invented personal or professional details.

**Tools:** Python, Streamlit, Ollama, Qwen2.5, and Markdown-based knowledge content.

**Outcome:** The website and assistant are being tested. Knowledge-file content and chatbot response behavior are still being validated.
